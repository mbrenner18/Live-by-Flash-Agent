# Live by Flash — AI Frontier Analysis Agent

Live by Flash is a multimodal AI agent that analyzes emerging research and organizes it into interactive clusters, helping users understand the rapidly evolving AI landscape.

## 🧠 What It Does

Live by Flash transforms raw research inputs into structured, visual intelligence.

Users can:
- Input research topics or links
- Generate AI-powered clusters of related ideas
- Explore connections between papers and concepts
- Visualize emerging trends in an interactive interface
